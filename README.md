# Hochelaga Archipelago — Credits Prototype

A standalone credits page for CART 470, inspired by watercolor maps and river journeys.

## Preview locally

Extract the ZIP and open `index.html` in your browser. No installation, build step, server, or internet connection is required.
Keep all five files in the same folder:

- `index.html`: page structure and title.
- `style.css`: layout, watercolor river, paper texture, and comic speech bubble.
- `script.js`: credit data, scrolling, motion controls, and seagull interaction.
- `boat.js`: projected 3D paper boat geometry and rendering.
- `README.md`: setup and editing instructions.

## Features

- Hochelaga Archipelago title and scrolling credit sections.
- Watercolor river with animated current lines.
- A paper boat that follows the river as you scroll.
- A slightly elevated side view of the boat, with subtle rocking and smooth turns.
- A clickable seagull with an attached comic speech bubble.
- Responsive layout, keyboard controls, and reduced-motion support.

The watercolor highlight beside names has been removed.

## Edit the credits

Edit `creditGroups` near the top of `script.js`. Each person has a `role` and `name`.
The project team and Liz Miller are real entries. All other names and supporting roles are fictional placeholders for testing; replace them before using this as a final credit list.
Team roles and Liz's collaborator label are provisional.

## Paper boat

`boat.js` draws a small 3D mesh using Canvas, with depth-sorted paper faces and subtle shading. It does not require external models or libraries.
The camera is tilted 38 degrees away from a straight overhead view. Roll is capped at 4 degrees, and pitch at approximately 1.1 degrees.
The boat follows scrolling even when water motion is paused. Pausing stops its extra rocking; reduced-motion mode also removes turn easing.

## Seagull interaction

Click the seagull to open its speech bubble. Click again to cycle through five lines. Press Escape while focused within the interaction, or wait seven seconds to close it.
The bubble uses one closed SVG outline for both its body and tail, avoiding a seam between separate borders.
Keyboard users can reach the seagull with Tab and activate it with Enter or Space.

## Publish a test repository

Suggested repository name: `CART470-Credits-Test`.
Place all five files in the repository root. Configure GitHub Pages to publish that root directory from your chosen branch.
This package does not create a repository or deploy the page automatically.

## Link back to the map

Set `MAP_URL` in `script.js` to the actual map URL. When empty, the final link returns to the top of this prototype.

## Integrate into React later

Reuse the credit data and move the page into a dedicated component. Scope the CSS to the credits page instead of copying global styles into the main application.
Register event listeners, observers, timers, and animation loops inside effects, and clean them up when the component unmounts.

## Validation

JavaScript syntax has been checked with `node --check`. Boat projection calculations were checked across multiple headings and roll angles.
Browser visual and interaction testing could not be completed in the current environment. Check the full scroll journey, speech bubble, pause control, and narrow-screen layout locally.

All artwork is generated by the included CSS, SVG, and Canvas code. No external assets or fonts are required.

## River extras

The boat leaves fading ripples as it moves. Ripples stop forming when stationary, paused, or in reduced-motion mode.
During the final 260 pixels of scrolling, the boat eases into a berth beside a small dock. Scrolling back up releases it.
Edit gullLines in script.js to change the seagull dialogue.

## Dock and wake style

The dock uses the same 38-degree orthographic camera tilt as the boat. Raised planks, end grain, nail heads, posts, water rings and a soft shadow define its depth. Muted olive outlines and cream wood match the paper-map palette.
The wake uses the original single pale arc, enlarged from 28 × 12 to 34 × 15 pixels. It expands and fades over 1.8 seconds.
The message bottle has been removed, including its dialog and styles.

The dock is horizontal and its final berth is offset 48 pixels toward the right bank from the river centerline. The boat turns to align with the dock during arrival.
